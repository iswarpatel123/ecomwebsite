# Reviews

Customer reviews summary (score, bars, recommend %) plus a list with show-more.

## When to use

- PDP review blocks

## When to avoid

- Third-party widget embeds that already own layout

## Import

```tsx
import { Reviews, type ReviewItem } from "@repo/storefront-patterns";
```

## Accessibility

- Section labelled by title
- Star ratings exposed via `aria-label`
- Helpful votes are real buttons
